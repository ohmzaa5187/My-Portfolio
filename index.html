2. WALLET-TRACK (AWS Serverless Expense Tracker)

เว็บแอปพลิเคชันจัดการรายจ่ายและควบคุมงบประมาณ พัฒนาด้วยสถาปัตยกรรม AWS Serverless รองรับการโฮสต์บน Amazon S3 Static Website ประมวลผลไฟล์ .csv อัตโนมัติด้วย AWS Lambda (Python 3.12) จัดเก็บข้อมูลลง Amazon DynamoDB และมีระบบ Amazon SNS แจ้งเตือนงบประมาณเกินกำหนดเข้าอีเมลโดยตรง

  • Static Website Hosting บน Amazon S3 พร้อม CORS & Bucket Policy
  • Event-Driven Automation ด้วย AWS Lambda เมื่ออัปโหลดไฟล์ .csv
  • NoSQL Database ออกแบบตาราง ExpenseTracker บน DynamoDB
  • Real-time Budget Alert แจ้งเตือนผ่าน Amazon SNS เมื่อรายจ่ายเกินยอด
